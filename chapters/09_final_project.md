# 09. Final Project

## 오늘의 결과물

이번 장에서는 수업에서 배운 C++ 개념을 사용해 하나의 콘솔 기반 프로그램을 직접 설계하고 구현합니다.

최종 프로젝트는 단순히 코드를 많이 쓰는 과제가 아닙니다. 어떤 데이터를 다룰지 정하고, 클래스로 구조를 만들고, 기능을 함수로 나누고, 파일 저장까지 연결하는 종합 실습입니다.

## 프로젝트 목표

- 문제를 직접 정하고 프로그램 요구사항으로 바꿀 수 있다.
- 필요한 클래스를 설계할 수 있다.
- 데이터를 <mark>vector</mark> 또는 <mark>map</mark>으로 관리할 수 있다.
- 기능을 함수와 멤버 함수로 분리할 수 있다.
- 파일 저장 또는 불러오기를 구현할 수 있다.
- 입력 검증이나 예외 처리를 포함할 수 있다.

## 1단계: 만들 프로그램 정하기

먼저 너무 큰 주제를 피하고, 콘솔에서 입력과 출력으로 확인할 수 있는 프로그램을 고릅니다.

추천 주제는 다음과 같습니다.

- 도서 관리 프로그램
- 학생 성적 관리 프로그램
- 은행 계좌 관리 프로그램
- Todo List 프로그램
- 간단한 RPG 캐릭터 관리 시스템
- 영화 예매 관리 시스템

좋은 주제는 데이터가 분명합니다. 예를 들어 도서 관리 프로그램이라면 <mark>Book</mark>이라는 데이터가 있고, 제목, 저자, 대출 여부 같은 속성이 있습니다.

## 2단계: 핵심 데이터 찾기

프로그램에서 관리할 대상을 먼저 정합니다.

| 프로젝트 | 핵심 클래스 예시 | 주요 데이터 |
|---|---|---|
| 도서 관리 | `Book` | 제목, 저자, 대출 여부 |
| 성적 관리 | `Student` | 이름, 점수, 등급 |
| 은행 계좌 | `Account` | 계좌번호, 소유자, 잔액 |
| Todo List | `Todo` | 내용, 완료 여부 |
| 영화 예매 | `Movie`, `Reservation` | 영화명, 좌석, 예매자 |

클래스는 프로그램에서 계속 함께 다니는 데이터를 묶는 단위입니다.

## 3단계: 기능 목록 만들기

처음부터 모든 기능을 만들려고 하지 말고 필수 기능부터 정합니다.

예를 들어 도서 관리 프로그램이라면:

- 책 추가하기
- 책 목록 출력하기
- 제목으로 검색하기
- 대출 상태 변경하기
- 파일에 저장하기
- 파일에서 불러오기

기능 이름은 나중에 함수 이름이 될 수 있습니다.

```cpp
void addBook(vector<Book>& books);
void printBooks(const vector<Book>& books);
int findBookByTitle(const vector<Book>& books, string title);
void saveBooks(const vector<Book>& books, string filename);
```

## 4단계: 클래스 초안 만들기

먼저 가장 중요한 클래스 하나를 설계합니다.

```cpp
class Book {
private:
    string title;
    string author;
    bool borrowed;

public:
    Book(string t, string a) {
        title = t;
        author = a;
        borrowed = false;
    }

    void print() {
        cout << title << " / " << author << endl;
    }
};
```

이 단계에서는 완벽한 설계보다 “프로그램의 데이터를 코드로 표현할 수 있는가”가 더 중요합니다.

## 5단계: 작은 버전부터 완성하기

최종 프로젝트도 이전 장들과 같은 방식으로 키웁니다.

## 프로젝트 v1: 데이터 추가와 출력

- 클래스 1개를 만든다.
- 객체 2~3개를 <mark>vector</mark>에 넣는다.
- 목록을 출력한다.

```cpp
vector<Book> books;
books.push_back(Book("C++ Primer", "Lippman"));
books.push_back(Book("Effective C++", "Meyers"));

for (Book book : books) {
    book.print();
}
```

## 프로젝트 v2: 사용자 입력과 검색

- 사용자에게 데이터를 입력받는다.
- 검색어를 입력받아 원하는 항목을 찾는다.
- 찾지 못한 경우 메시지를 출력한다.

검색 함수는 다음처럼 만들 수 있습니다.

```cpp
int findBookByTitle(const vector<Book>& books, string title) {
    for (int i = 0; i < books.size(); i++) {
        if (books[i].getTitle() == title) {
            return i;
        }
    }
    return -1;
}
```

## 프로젝트 v3: 파일 저장과 불러오기

- 프로그램 종료 전에 파일에 저장한다.
- 프로그램 시작 시 파일에서 불러온다.
- 파일이 없을 때도 프로그램이 중단되지 않게 한다.

파일 형식은 처음에는 단순하게 한 줄에 하나씩 저장해도 됩니다.

```text
C++ Primer,Lippman,0
Effective C++,Meyers,1
```
