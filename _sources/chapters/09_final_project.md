# 09. Final Project

## 목표

수업에서 배운 C++ 개념을 사용해 하나의 콘솔 기반 프로그램을 설계하고 구현합니다.

## 프로젝트 후보

- 도서 관리 프로그램
- 학생 성적 관리 프로그램
- 은행 계좌 관리 프로그램
- Todo List 프로그램
- 간단한 RPG 캐릭터 관리 시스템
- 영화 예매 관리 시스템

## 필수 요구사항

- 클래스 2개 이상 사용
- `vector` 또는 `map` 사용
- 함수로 기능 분리
- 파일 저장 또는 불러오기
- 예외 처리 또는 입력 검증 포함

## 제출물

- 소스코드
- 실행 방법
- 주요 기능 설명
- 클래스 설계 설명
- 실행 화면 캡처 또는 출력 예시
