# C++ 입문에서 프로젝트까지

이 책은 C++ 문법을 순서대로 암기하기보다, 작은 프로그램을 직접 만들면서 필요한 개념을 익히는 방식으로 구성되어 있습니다.

## 수업 목표

- C++ 프로그램의 컴파일과 실행 흐름을 이해한다.
- 변수, 조건문, 반복문, 함수, 배열, 포인터, 참조를 사용할 수 있다.
- 클래스와 객체 지향 프로그래밍의 기본 구조를 이해한다.
- 상속, 다형성, 템플릿, 예외 처리, 파일 입출력, STL을 프로젝트에 적용한다.
- 최종적으로 하나의 콘솔 기반 C++ 프로젝트를 설계하고 구현한다.

## 장 구성

각 장은 다음 순서로 진행합니다.

1. 오늘 만들 것
2. 필요한 개념
3. 최소 동작 코드
4. 코드 읽기
5. 기능 추가 Mission
6. 자주 나는 에러
7. 과제
8. 체크리스트
